# QR//FAULT — 故障模式二维码生成器

一个**故意不好用**的二维码生成器：无论你输入什么，它都不会把输入写进二维码，而是从 160 条错误文本中随机挑一条，生成一个**真正可扫描、但内容一定是错误**的二维码。

> 本项目仅供娱乐、交互演示和前端练习，请勿用于正式业务或任何需要正确二维码的场景。
>
> **状态：** intentionally broken · **错误文本：** 160 条 · **构建：** 单文件、离线可用

---

## 快速开始

无需安装依赖，直接用浏览器打开：[qr-fail-generator.html](qr-fail-generator.html)

```text
qr-fail-generator.html
```

Windows 也可以：

```powershell
start .\qr-fail-generator.html
```

页面完全离线运行，不会发起网络请求。

## 它到底有多不好用

- 输入框可以正常输入，但内容**只参与字符数统计**，随后被丢弃。
- 点击「生成二维码」后，会播放一段认真但注定失败的生成进度。
- 二维码内容只可能是：`生成失败`、`乱码`、`无内容`、`错误代码`、`校验失败`、`数据损坏`、`404`、`权限不足`、`生成超时`、`编码异常`。
- 下载得到的 PNG 也是错误二维码，不会还原输入内容。
- 页面明确标注「整蛊模式」和「仅供演示」。

## 功能

### 160 条错误文本

错误池按 10 个类别组织，每类 16 条，共 **160 条互不重复**的文本：

| 类别 | 数量 | 示例 |
| --- | ---: | --- |
| 生成失败 | 16 | `生成失败：内容被系统安全遗忘` |
| 乱码 | 16 | `锟斤拷锟斤拷烫烫烫烫` |
| 无内容 | 16 | `无内容：二维码只是一个空壳` |
| 错误代码 | 16 | `错误代码：QR-CODE-1A2B / 无法归类` |
| 校验失败 | 16 | `校验失败：CHECKSUM MISMATCH` |
| 数据损坏 | 16 | `数据损坏：字节序错乱` |
| 内容未找到 | 16 | `ERROR 404: QR CONTENT NOT FOUND` |
| 权限不足 | 16 | `权限不足：只允许生成错误` |
| 生成超时 | 16 | `生成超时：等待一个不会来的结果` |
| 编码异常 | 16 | `编码异常：代理对损坏` |

选择逻辑会避开最近出现过的类别和文本，减少连续重复。

### 真正可扫描

- 使用 `qrcode-generator 1.4.4` 生成 QR 矩阵。
- UTF-8 Byte 模式。
- H 级纠错（30%）。
- 4 个模块的静区。
- Canvas 内部尺寸 1024 × 1024，下载清晰。
- 页面上的二维码和下载的 PNG 都经过回读验证。

### 失败日志

- 记录最近 **160 次**失败。
- 日志区域固定最大高度，支持鼠标滚轮、触控板、手机滑动上下查看。
- 新记录自动回到日志顶部。
- 每条日志包含时间、错误类型、错误码、二维码实际内容和失败状态。

### 交互细节

- 生成过程包含逐步失败进度和日志输出。
- 展示任务编号、有效载荷大小、校验结果、耗时。
- 支持「下载这张废码」和「再失败一次」。
- 设置项点击后会提示「已忽略：反正都会失败」。
- 响应式布局，桌面和手机均可使用。
- 支持 `prefers-reduced-motion`。

## 工作原理

```text
用户输入
   │
   ├─ 只读取长度 ──────────────► 显示「已丢弃 N 个字符」
   │
   └─ 内容不进入编码器

错误文本池（160 条）
   │
   ├─ 避开最近 2 个类别
   ├─ 避开最近 24 条文本
   └─ 随机选择一条
          │
          ▼
   生成错误码 QR-<TYPE>-<4HEX>
          │
          ▼
   替换 {code} 占位符
          │
          ▼
   qrcode-generator（UTF-8 / H 级纠错）
          │
          ▼
   1024 × 1024 Canvas → 页面展示 / PNG 下载
```

关键实现位置都在 `qr-fail-generator.html`：

- `ERROR_TYPES`：10 个类别及每类 16 条错误文本。
- `chooseError()`：类别与文本的避重选择。
- `drawQR()`：生成并绘制二维码。
- `renderResult()`：更新结果面板与元数据。
- `addHistory()`：写入并重绘失败日志。
- `download()`：导出 PNG。

## 自定义

### 增加错误文本

在 `ERROR_TYPES` 中对应类别的 `variants` 数组里追加字符串即可：

```js
variants: [
  '生成失败',
  '生成失败：你的新错误文案'
]
```

如果文案里需要动态错误码，使用 `{code}` 占位符：

```js
'错误代码：{code} / 新错误'
```

### 调整日志数量

修改两处：

```js
state.history = state.history.slice(0, 160);
```

以及页面顶部的「最近 160 次」文案。

### 调整日志滚动高度

```css
.log-body {
  max-height: 246px;
  overflow-y: auto;
}
```
